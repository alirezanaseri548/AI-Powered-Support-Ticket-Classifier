# AI-Powered Support Ticket Classifier

A production-style full-stack portfolio project built step by step.

## Stack
- React web frontend
- React Native mobile app
- NestJS backend
- PostgreSQL with Prisma
- JWT authentication
- Role-based access control
- FastAPI ML microservice
- AI-based support ticket classification

## Project Structure
- backend: NestJS API
- frontend-web: React web app
- mobile-app: React Native app
- ml-service: FastAPI machine learning service
