# AI-Powered Support Ticket Classifier

A production-style AI SaaS project for classifying customer support tickets using a full-stack architecture.

## Stack

- Backend: NestJS, TypeScript, Prisma ORM
- Database: PostgreSQL
- Frontend: React, Vite, TypeScript
- ML Service: FastAPI
- DevOps: Docker, Docker Compose
- Mobile: React Native placeholder

## Project Structure

- backend
- frontend
- ml-service
- mobile-app
